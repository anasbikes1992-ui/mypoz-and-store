Report catalog

  • Sales — by day, cashier, branch, payment, hourly
  • Profit — gross profit by product / category / period
  • Products — best / worst sellers, dead stock
  • Inventory — valuation, ledger, low-stock, expiry
  • Purchases — by supplier, purchase vs sales
  • Expenses — by category, profit & loss

  • Customer — dues, statements, loyalty verify
  • Tax — VAT collected verify
  • Audit — activity log by user / entity

Confirmed from the live system — decisions to steer the build

The full module set is now mapped from the real screens (home launcher, business menu, products list, billing engine). To sequence a ~55-module build, I need a few calls:

  1. Reselling model — one shared multi-tenant cloud (each client an org), a per-client white-label deploy, or both.
  2. Priority verticals — which sale modes to build first (retail is done-ish; restaurant, delivery, repair, rooms, reloads…).
  3. UI direction — keep the familiar tile launcher, modernised, or a modern sidebar app.

Optional refinements: the Admins/roles and Settings screens, one report layout, and a receipt sample.
